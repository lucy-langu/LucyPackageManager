# مدیریت پکیج لوسی (LPM) 🚀

سلام! به مخزن LPM (Lucy Package Manager) خوش اومدی. 
این ابزار رو نوشته شده تا یه سیستم مدیریت پکیج اختصاصی، خیلی سریع و البته امن برای زبان برنامه‌نویسی "لوسی" داشته باشیم. این پکیج‌منیجر با C++ نوشته شده و مخصوص لینوکسه.

## چرا LPM خفنه؟ 

- **راحتی خودت (.plm):** وقتی پروژه‌ت رو با `lpm package` خروجی می‌گیری، کل سورس‌کد با الگوریتم XOR قفل و کمپرس میشه.
- **نصب تودرتو (Recursive):** اگه پکیجت وابستگی داره (توی پوشه `lib/`)، LPM به صورت هوشمند میره داخلشون و همه وابستگی‌ها رو تا بی‌نهایت سطح استخراج و نصب می‌کنه. 
- **ظاهر مینیمال و شیک:** توی ترمینال خبری از لودینگ‌های زمخت نیست؛ یه لاین متحرک تمیز داره و لیست پکیج‌ها رو هم توی جدول مرتب نشون میده. 

## آموزش نصب 🛠️

نیازی به کامپایل سورس کد نیست؛ فایل آماده و کامپایل‌شده‌ی `lpm` داخل مخزن قرار داره.
فقط کافیه فایل `install.sh` رو اجرا کنی تا فایل باینری به درستی توی سیستم کپی بشه و بره توی `PATH`:

```bash
chmod +x install.sh
./install.sh
```

## لیست دستورات 💻

- ساخت پروژه جدید (پوشه `my-package/` و فایل‌های اولیه):
  ```bash
  lpm init
  ```
- پک کردن پروژه فعلی به فایل امن `.plm`:
  ```bash
  lpm package
  ```
- نصب پروژه فعلی توی سیستم:
  ```bash
  lpm install
  ```
- نصب یک فایل `.plm` (و تمام وابستگی‌هاش):
  ```bash
  lpm install --lpm package_name.plm
  ```
- لیست پکیج‌های نصب‌شده:
  ```bash
  lpm list
  ```
- دیدن مشخصات یه پکیج خاص:
  ```bash
  lpm info <name>
  ```
- حذف یه پکیج از سیستم:
  ```bash
  lpm uninstall <name>
  ```
